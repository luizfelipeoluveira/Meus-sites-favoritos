# 🌐 Meus Sites Favoritos

## 📌 Sobre o projeto

Este projeto consiste em uma página web desenvolvida utilizando HTML5, com o objetivo de apresentar uma lista de sites e plataformas que fazem parte do meu cotidiano.

A página reúne seis plataformas favoritas, cada uma representada por sua respectiva imagem e um link que permite ao usuário acessar diretamente o site oficial.

O projeto foi desenvolvido durante meus estudos de **Desenvolvimento Web**, como uma atividade prática para aplicar os primeiros conceitos da linguagem HTML.

## 🚀 Tecnologias utilizadas

- **HTML5:** Linguagem de marcação utilizada para estruturar o conteúdo da página.

## 📚 Conhecimentos aplicados

Durante o desenvolvimento deste projeto, foram trabalhados os seguintes conceitos:

- **Estrutura básica do HTML5:** utilização das tags `<!DOCTYPE html>`, `<html>`, `<head>` e `<body>`.
- **Metadados:** utilização das meta tags `charset` e `viewport` para configurar a codificação de caracteres e a visualização em diferentes dispositivos.
- **Títulos:** utilização da tag `<title>` para definir o título exibido na aba do navegador.
- **Cabeçalhos:** utilização da tag `<h1>` para apresentar os títulos dos conteúdos.
- **Imagens:** utilização da tag `<img>` para inserir imagens na página, aplicando os atributos `src`, `alt`, `width` e `height`.
- **Links:** utilização da tag `<a>` com o atributo `href` para direcionar o usuário a outros sites.
- **Navegação em novas abas:** aplicação do atributo `target="_blank"` para abrir os links em uma nova aba.
- **Organização de conteúdo:** utilização das tags `<figure>` e `<figcaption>` para agrupar imagens e suas respectivas legendas.
- **Comentários em HTML:** utilização de `<!-- -->` para identificar e organizar partes do código.

## 🖥️ Sites apresentados

A página apresenta as seguintes plataformas:

1. PlayStation App
2. Shopee
3. Instagram
4. TikTok
5. WhatsApp

## 🎯 Objetivo do projeto

Colocar em prática os fundamentos iniciais do HTML5, desenvolvendo uma página web simples e funcional, explorando a inserção de imagens, criação de links e organização de elementos.

Este projeto representa uma das primeiras etapas da minha jornada no Desenvolvimento Web, servindo como base para o aprendizado de tecnologias como CSS e JavaScript.
